# UTSAV2K26
A dedicated event management and symposium coordination platform for the UTSAV 2026 technical event.

## Overview
UTSAV2K26 is a comprehensive platform designed to streamline event registration, management, and coordination for technical symposiums. It features cinematic intro sequences, dynamic event tracking, and integrated Google Apps Script for backend data management.

## Key Features
- Cinematic intro sequences with thunder effects.
- Dynamic registration flow with gender locking and sheet routing.
- Real-time attendance logging and team management.
- Admin panel for event timings and logical fixes.
